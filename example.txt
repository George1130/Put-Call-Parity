Put-Call Parity — working example commands
==========================================

CLI (put_call_parity.py)
------------------------
Interactive mode (prompts for quotes):
    python put_call_parity.py

Manual mode (all six inputs required):
    python put_call_parity.py --spot 100 --strike 100 --rate 5 --t 0.5 --call 8 --put 5

Manual mode with payoff diagram:
    python put_call_parity.py --spot 100 --strike 100 --rate 5 --t 0.5 --call 8 --put 5 --plot

Live market scan (nearest viable expiry):
    python put_call_parity.py --ticker AAPL

Live scan with options:
    python put_call_parity.py --ticker AAPL --expiry 2026-09-18 --no-dividends --loose
    python put_call_parity.py --ticker ^SPX --top 10
    python put_call_parity.py --ticker ^NDX --rf 4.2 --top 8

See full flag reference with:
    python put_call_parity.py --help

GUI (main.py — requires a graphical display)
---------------------------------------------
    python main.py

Web app (app.py — Flask, open http://127.0.0.1:5000)
------------------------------------------------------
    python app.py
    PORT=8080 python app.py        # custom port

Web API examples (curl):
    curl -X POST http://127.0.0.1:5000/api/analyze \
         -H "Content-Type: application/json" \
         -d '{"S": 100, "K": 100, "r": 5, "T": 0.5, "C": 8, "P": 5}'
    curl "http://127.0.0.1:5000/api/live?ticker=AAPL"
    curl "http://127.0.0.1:5000/api/expirations?ticker=AAPL"
    curl "http://127.0.0.1:5000/api/chart?S=100&K=100&r=5&T=0.5&C=8&P=5" -o payoff.png
